Quick start

Building a plugin? Start with the plugin docs (especially ai-guide.md), then use widgets/events/permissions/API as references.

  1. Create backend/storage/addons/{identifier}/ with conf.yml + AppPlugin entry class
  2. Add Routes/, Frontend/widgets.json, or sidebar pages as needed
  3. Pull machine-readable dumps from /rag/ into your RAG index
Machine-readable sources (.md / .json) are published next to these pages for RAG and AI agents. See RAG index or llms.txt.
