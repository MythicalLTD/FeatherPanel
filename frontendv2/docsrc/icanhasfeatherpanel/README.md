# icanhasfeatherpanel source

Committed inputs only. One command builds the full site into `public/icanhasfeatherpanel/` (gitignored).

## Committed here

- `plugins/*.md` — plugin authoring guides (HTML index is generated by the build)
- `assets/` — docs CSS/JS
- `schemas/` — JSON schemas
- `plugin-power.html`, `plugin-themes.html` — static reference pages

## Build everything

```bash
cd frontendv2
pnpm export:docs           # widgets, pages, permissions, events, API, CLI, settings, installer, plugins index, RAG
pnpm build:public-docs     # export:docs + assemble GitHub Pages → ../docs-site/
pnpm build:with-docs       # export:docs + Next production build
```
